# Case Studies (Raw Intake)

Data mentah studi kasus **sebelum** masuk Knowledge Graph — draf,
kandidat, sumber materi yang belum lolos QA struktural (§12.1: traceability
check, non-duplication check, copyright/asset check).

Alur: `case-studies/raw/*` → review kontributor → jika lolos §12.1, ditulis
ulang sebagai node terstruktur di `knowledge-graph/nodes/case-studies/*.md`
mengikuti `core/schemas/knowledge-graph/case-study.schema.json`.

Folder ini bukan sumber kebenaran graph — ia adalah *staging area*. Lihat
`contrib/CONTRIBUTING.md` untuk proses kontribusi lengkap.
